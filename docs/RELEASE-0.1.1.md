# RenPy Studio 0.1.1 — живой предпросмотр и редактор переводов

Новая нумерация: проект ещё никто не видел, поэтому внутренние 0.2–0.4 схлопнуты
в публичную **0.1.1**. Всё, что было в 0.2–0.4, входит в неё.

## Живой предпросмотр (live-reload)

Предпросмотр экрана больше не одноразовый: студия поднимает локальный мост,
игра сама спрашивает его, и правки попадают в уже запущенное окно.

- **Мост** — TCP на `127.0.0.1`, случайный порт и одноразовый токен в каждом запросе.
  Наружу ничего не открывается, чужой процесс с тем же файлом предпросмотра мост
  не найдёт и не сможет управлять игрой.
- **Кнопка «Обновить в игре»** рядом с «Проверить в игре»: перечитывает `.rpy`
  (`renpy.reload_script()`) и показывает экран заново — без перезапуска студии.
- **Готовность** видна честно: кнопка отвечает «экран перезагружен» только когда
  игра действительно дошла до предпросмотра (игра сообщает `ready=1` в опросе).
  Если предпросмотр не запущен — «предпросмотр не запущен», а не тихий успех.

### Безопасность забытого файла

Временный `game/zz_studio_preview.rpy` активируется **только** переменными окружения,
которые выставляет студия (`RENPY_STUDIO_PREVIEW`, `RENPY_STUDIO_BRIDGE`).
Если студия упадёт и файл останется, обычный запуск игры ничего не заметит.

Главное меню подменяется через `config.label_overrides`, а не вторым
`label main_menu`. Раньше это ломало проекты со своим главным меню
(«Label 'main_menu' is defined twice») — теперь конфликта нет.

## Редактор переводов

Новый раздел **GUI → Переводы**:

- таблица: строка — реплика/пункт выбора/подпись зоны, колонки — языки проекта;
- покрытие по каждому языку в процентах, «только пустые» и поиск по исходнику и переводу;
- правка сохраняется при уходе из поля, undo/redo работает как везде;
- **«Сгенерировать tl»** — вызов `renpy translate` через SDK, отчёт «файлов N».

## Установщик

Теперь собирается два артефакта: установщик Inno Setup и портативный zip.

- **Inno Setup**, установка в профиль пользователя (права администратора не нужны),
  стабильный `AppId` для обновлений, `MinVersion=10.0`.
- **WebView2** проверяется по факту наличия рантайма; если его нет — ставится
  из вложенного `MicrosoftEdgeWebview2Setup.exe` (≈1,9 МБ), без похода в браузер.
- **Ассоциация `.rpyproj`**: двойной клик по маркеру проекта открывает студию
  с этим проектом (`renpy-studio.exe "<путь>"`); в меню «Открыть с помощью» студия
  тоже видна. Ассоциацию можно не ставить — галочка в установщике.
- **Rust и Node в установщик не входят** — это инструменты сборки, пользователю
  нужен только собранный exe. Ren'Py SDK тоже не вкладывается (сотни мегабайт и
  своя лицензия): студия находит его сама или просит путь.
- `SHA256SUMS.txt` рядом с артефактами — для проверки скачанного.

Сборка: `powershell -File scripts\build-release.ps1` (версия, exe, установщик, zip, хеши).

## Единый источник версии

`node scripts/set-version.mjs 0.1.1` (и `npm version`) правит `package.json`,
`src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json` и `src/version.ts` за один раз.
Идентификатор приложения — `dev.renpystudio.desktop` (прежний заканчивался на `.app`
и конфликтовал с macOS-бандлами; менять его позже — ломать путь обновления).

## Исправления по аудиту

- Русский текст в шаблонах экранов генерируется по локали проекта: в англоязычной
  новелле не будет «Назад», «Пусто», «Да/Нет».
- Авто-lint после включения плагина больше не блокирует интерфейс: полный экспорт
  на каждый клик был тяжёлым на больших проектах.
- Предпросмотр и запуск больше не оставляют процессов: `renpy.exe` — лаунчер,
  раньше убивался только он, а игра продолжала работать и мешала следующему запуску.
- Относительный путь к проекту больше не превращается в verbatim-путь `\\?\E:\…`
  (Ren'Py с таким префиксом не открывает файлы) — теперь путь нормализуется
  без префикса, с схлопыванием `.` и `..`.
- `pause 0.1 hard` в harness не разбирается Ren'Py 8 — заменено на `renpy.pause()`.
- Поток опроса после `reload_script()` завершается молча, а не пишет traceback в `log.txt`.
