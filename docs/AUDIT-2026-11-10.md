## Что осталось доделать (по приоритету)

1. **Drag&drop ассетов из проводника** (ТЗ §9.1) — сейчас библиотека только читает `game/images|audio`.
2. **Граф: полноценный block-level режим** — «Всё» показывает сцены, выборы, условия и метки,
   но не каждый блок; нет перетаскивания рёбер и поиска по графу (ТЗ §9.3).
3. **Переводы новеллы** — тексты хранятся по локалям, но файлы `tl/<lang>` не генерируются;
   нужен вызов SDK `renpy translate` и кнопка в UI (ТЗ §9.4).
4. **Производительность больших проектов** — виртуализация ленты сцен и графа (ТЗ §18, 5000 блоков).
5. **Сборка релизов** — проверить пакеты `linux`/`mac` на практике, показывать прогресс и требования SDK.
6. **Внешние правки .rpy** — есть баннер и перечитывание, но нет diff-отчёта «что именно изменилось».
7. **ИИ-ассистент (v2)** — только настройки провайдера, как и заявлено в ТЗ для v1.
8. **Подпись установщика** — SmartScreen будет предупреждать.
9. **Мелочи UI** — горячие клавиши для добавления блоков, контекстное меню карточек, настройка шаблонов
   остальных экранов (настройки/загрузка/About) вместо стандартных Ren'Py.

## Известные ограничения, заложенные осознанно

- Импорт «best effort»: сложные конструкции (ATL, вложенные меню в условиях, `call screen`) уходят
  в блок «Код» без потери работоспособности.
- Постоянной синхронизации `.rpy → блоки` нет (ТЗ §8.2).
- `screen main_menu` генерируется отдельным файлом и перекрывает шаблонный экран; для импортированных
  проектов генерация меню отключается (`template = classic`).

## Второй проход (функции из списка «осталось»)

Реализовано:

1. **Drag&drop ассетов** — окно принимает файлы из проводника (`onDragDropEvent`), бэкенд
   `asset_import` копирует их в `game/images|audio|fonts|video` без перезаписи (суффикс `_2`),
   проверка покрыта юнит-тестом. Плюс кнопка «Импортировать файлы…» в библиотеке.
2. **Граф** — режим «Всё» строит block-level карту: сцены колонками, все блоки цепочкой,
   переходы из меню/условий/кода; поиск по названию сцены с переходом к найденному,
   перепривязка рёбер (`node_retarget`) для jump/menu/if; `onlyRenderVisibleElements`.
3. **Переводы** — кнопка в настройках проекта вызывает SDK `renpy translate <lang>`,
   показывает количество созданных `tl/<lang>/*.rpy`. Проверено: 8 файлов для `en`.
4. **Производительность** — линейная раскладка block-level графа без dagre, ленивый рендер узлов,
   `content-visibility` у карточек; для >600 блоков цепочные рёбра отключаются, остаются только переходы.
5. **Сборка** — потоковый журнал `studio://build-log`, статус `project_build_status`,
   определение артефакта в `dist`, ошибка «пакеты не выбраны» вместо ложного успеха.
6. **Внешние правки** — `external_diff` строит построчный diff (similar) с контекстом ±2 строки,
   кнопка «Показать файлы» в баннере.
7. **UI** — горячие клавиши (Ctrl+K — палитра, Delete — удалить блок, Ctrl+D — дублировать,
   Alt+↑/↓ — переместить), контекстное меню карточки блока.

Осталось:

- ИИ-ассистент (v2) и подпись установщика (нужен сертификат).
- Полная виртуализация списка сцен и графа для экстремальных проектов.
- Проверка пакетов linux/mac на живом SDK.
- Шаблоны экранов настроек/загрузки/About (сейчас стандартные Ren'Py).

## Третий проход (0.1.1): живой предпросмотр, переводы, установщик

| Область | Проблема | Исправление |
|---|---|---|
| Предпросмотр | Одноразовый: любая правка требовала перезапуска игры | Мост IDE↔игра (`bridge.rs`): TCP на 127.0.0.1, случайный порт, токен в запросе, очередь из 16 команд; кнопка «Обновить в игре» (`reload_script`) |
| Предпросмотр | Harness объявлял `label main_menu` — в проекте со своим главным меню это «Label 'main_menu' is defined twice» | Подмена через `config.label_overrides["main_menu"]`, авторская метка не трогается |
| Предпросмотр | `pause 0.1 hard` не разбирается Ren'Py 8 (в 0.4.0 harness был нерабочим) | `$ renpy.pause(0.15)` |
| Предпросмотр | Текст подсказки и «экран не найден» всегда по-русски | Строки выбираются по локали проекта |
| Предпросмотр | Повторный запуск игры оставлял живой процесс: `renpy.exe` — лаунчер, убивался только он | `taskkill /T /F /PID` — гасится всё дерево процессов |
| Предпросмотр | Относительный путь к проекту ломал запуск (`current_dir` + относительный аргумент) | `sdk::absolute()` — абсолютный путь без `\\?\`-префикса, с схлопыванием `.`/`..` |
| Предпросмотр | После `reload_script()` старый поток опроса писал traceback в `log.txt` | Поток завершается по `NameError` молча |
| UI | Кнопка «обновить» врала бы, если игра ещё не подключилась | Игра шлёт `ready=1`, только показав экран; без этого команда возвращает `false` и UI говорит «предпросмотр не запущен» |
| Переводы | Правка переводов только через инспектор по одному блоку | Раздел GUI → «Переводы»: таблица, покрытие, поиск, «только пустые», генерация `tl/<lang>` |
| Шаблоны | Русские подписи в генерируемых экранах (`«Назад»`, `«Пусто»`, `«Да/Нет»`) | `Ctx.locale` + `tr(ru, en)`, все дефолты по локали проекта |
| Плагины | Авто-lint после включения плагина блокировал UI на большом проекте | Запуск в фоне (`void lintAfterPlugins(...)`) |
| Сборка | Версия в четырёх местах вручную | `scripts/set-version.mjs` + npm-хук `version` |
| Сборка | `identifier` заканчивался на `.app` (конфликт с macOS-бандлами) | `dev.renpystudio.desktop` |
| Установщик | NSIS без проверки WebView2 и без ассоциации проекта | Inno Setup: per-user, WebView2 из вложенного bootstrapper, ассоциация `.rpyproj`, ярлыки, удаление, `MinVersion=10.0`, SHA256SUMS |
| CLI | Нельзя было проверить мост без GUI | `--preview <проект> <экран> [--hold N]` — печатает опросы и `ready` |
