# RenPy Studio 0.2.0 — что вошло в итерацию

Дата: 10 ноября 2026. База: 0.1.0 (фазы 0–6). Версия 0.2.0 закрывает три пункта хендоффа:
Point-and-Click, прогон плагинов «как есть», ИИ-ассистент v2.

## 1. Point-and-Click

Новый блок «Точки и клики» (`kind: pointclick`).

- Поля: фон (`bg`), необязательная строка сверху (`prompt`), список зон (`hotspots`).
- Зона: подпись (локализуемая), форма `rect` / `polygon`, координаты в долях экрана (0…1),
  действие `jump` / `tooltip` / `return`, цель перехода.
- Редактор зон — модальное окно с превью фона: рисование прямоугольника протяжкой,
  многоугольник по кликам, перетаскивание зон и вершин, изменение размера за уголки, удаление `Delete`.
  Предпросмотр фона идёт через протокол `studio-asset`.
- Генерация: на каждый блок создаётся `screen pc_<сцена>_<N>` в файле сцены.
  Фон — `add` по имени картинки из `images.rpy`; зоны — `button` с `xpos/ypos` в долях и
  `xysize` от `config.screen_width/height`, поэтому разрешение проекта не важно.
  Для многоугольников используется `focus_mask _StudioHit([...])` — класс с проверкой
  «точка внутри многоугольника» (Ren'Py вызывает callable с координатами и размерами кнопки).
  Подпись зоны показывается через `tooltip` + `GetTooltip()`, выход — `key "game_menu"`.
- Валидатор: ошибка на пустую цель перехода, предупреждения на пустой фон, отсутствие зон,
  нулевую площадь и отсутствие хотя бы одного выхода.
- Граф: зоны дают рёбра типа `choice` с подписью зоны, block-level режим показывает узел
  «Точки и клики», перепривязка рёбер работает (`node_retarget` обновляет зону).
- Граница файла: определение `screen` стоит после `label` на верхнем уровне; `srcmap`
  получает отдельный якорь, поэтому ошибки lint в экране ведут к блоку.

## 2. Плагины «как есть»

Проверено на реальных архивах из `plugins/`: `quiz`, `simple_inventory`, `tasks`
(и `sms_list` — она отключена из-за несовместимости самого плагина с Ren'Py 8.5).

Что выяснилось и исправлено:

| Проблема | Решение |
|---|---|
| Архив плагина — это демо-игра: внутри `gui.rpy`, `screens.rpy`, `options.rpy`, `script.rpy`, `tl/` | эти файлы и `tl/` не устанавливаются (`clean_target`) |
| ~80 файлов `gui/*` из демо перезаписывали оформление проекта | установка больше не перезаписывает существующие файлы |
| Удаление `.rpy` оставляло `*.rpyc`, и Ren'Py продолжал грузить плагин | `uninstall` удаляет и скомпилированный `.rpyc` |
| Общая зависимость `7DOTS.rpy` у нескольких плагинов удалялась при отключении одного | при отключении файлы, нужные другим включённым плагинам, сохраняются |
| `SMS.rpy:720` — `xalign` + `xanchor` | ошибка самого плагина на Ren'Py 8.5; студия не патчит чужой код |

Результат прогона: три плагина включены в тестовый проект, файлы на месте (`quiz.rpy`,
`simple_inventory.rpy`, `TASKS.rpy`, `7DOTS.rpy`, картинки), `renpy lint` без ошибок
(только предупреждения самих плагинов), игра запускается, отключение чистое.

## 3. ИИ-ассистент v2

- Rust-модуль `ai.rs`: `GET {base}/models` и `POST {base}/chat/completions` (ureq + rustls),
  повтор запроса без `temperature`, если провайдер её не принимает.
- Промпт собирается из проекта: сцены с id и метками, персонажи, переменные, блоки текущей сцены,
  каталог типов блоков. Ответ — на языке пользователя.
- Панель чата справа: список моделей из провайдера, выбор модели сохраняется в настройках,
  Enter — отправить, Shift+Enter — новая строка, ошибки показываются в ленте.
- Предложенные изменения приходят блоком `actions` (`add_scene`, `add_block`, `set_start_scene`),
  показываются списком и применяются только по кнопке «Применить»; после применения — тост и обновление графа.
- Ключ живёт в настройках, уходит только в заголовке `Authorization` из Rust, не логируется,
  в UI скрыт полем `password`.

## Проверки

- `npm run check` — TypeScript + полнота RU/EN.
- `scripts/cargo.ps1 test` — 12 тестов (включая экран point-and-click с полигоном и нормализацию путей ассетов).
- `scripts/e2e.ps1` — создание → экспорт → официальный `renpy lint` = 0 (в фикстуру добавлен point-and-click).
- Живой прогон в приложении через CDP: рисование зоны, сохранение, экспорт; чат с провайдером
  `tokenwave.ru` (77 моделей), ответ на вопрос о проекте, предложение `add_block` и его применение.
- Плагины: включение 4, отключение 1, lint, запуск игры (см. выше).

## Безопасность

- В коде и репозитории нет токенов и ключей. `docs/HANDOFF-PROMPT.md` содержит рабочие ключи —
  файл исключён из git и должен быть удалён/перевыпущен перед публикацией.
- Перед публичным релизом перевыпустить GitHub token и ключ провайдера.
