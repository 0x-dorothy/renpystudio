# RenPy Studio 0.4.0 — библиотека экранов и предпросмотр

Первая волна после разбора Morihime и VN Studio Pro: то, что превращает конструктор
экранов в рабочий инструмент для настоящих новелл.

## Библиотека шаблонов (12 экранов)

В разделе **GUI → Экраны** появился выбор «Из шаблона…». Шаблон создаёт готовый экран
с логикой; вы настраиваете только параметры (заголовок, колонки, списки).

| Шаблон | Что генерирует |
|---|---|
| Сохранение / загрузка | Сетка слотов, `FileScreenshot`, время, имя сейва, подтверждение перезаписи, удаление по Delete, страницы `FilePageNext/Previous` |
| Настройки | Скорость текста, автопрокрутка, пропуск, громкости музыки/звука/озвучки, режим окна, переключатель языка |
| Галерея CG | Сетка разблокируемых картинок, замочки, полноэкранный просмотр, `persistent.studio_gallery_unlocked` + `studio_unlock(image)` |
| Музыкальная комната | Список треков, клик — играть, «Стоп», подсветка играющего |
| Выбор главы | Кнопки глав, `Start(label)` |
| Уведомление | Всплывашка в углу с таймером, помощник `studio_notify_<имя>("текст")` |
| HUD | Панель поверх игры: заголовок главы и значение переменной |
| Подтверждение | Замена стандартного `confirm` (выход, перезапись, удаление) |
| Статистика | Список показателей из переменных |
| Дневник | Прокручиваемые записи: заголовок и текст |
| Инвентарь | Сетка предметов с картинками |
| Телефон | Лента сообщений: собеседник слева, «me» справа |

Экраны генерируются в `game/screens_builder.rpy` вместе с ручными. Открываются из сцены
блоком «Показать экран» или действием `Show`.

## Image-based UI

- Кнопка может быть `imagebutton` с картинками idle/hover — как в меню Morihime.
- У текстовой кнопки появился фон-картинка и 9-slice (`Frame(img, n, n)`): уголки не мылятся
  при растягивании.
- Всё это — поля в инспекторе элемента, без кода.

## Предпросмотр экрана в игре

Кнопка «Проверить в игре» на выбранном экране:

1. студия сохраняет проект и экспортирует `.rpy`;
2. пишет временный `game/zz_studio_preview.rpy` с подменой `label main_menu`, который
   показывает только этот экран на нейтральном фоне;
3. запускает игру; Esc закрывает предпросмотр;
4. файл удаляется при обычном запуске, остановке, экспорте и сборке.

Это ещё не live-reload (без моста IDE↔игра), но цикл «правка → посмотреть» сократился
с «дойти до экрана в игре» до одной кнопки.

## Проверено

- `cargo test` — 49 тестов (добавлены генерация всех 12 шаблонов и imagebutton/Frame).
- `clippy -D warnings` — чисто.
- `npm run check` — TypeScript + RU/EN.
- Фикстура e2e содержит все 13 экранных шаблонов: `renpy lint` = 0.
- Запуск игры с шаблонами — без traceback.
- Harness предпросмотра проверен вживую: игра стартует с экраном галереи, Esc выходит.

## Осталось из волны SSS/SS

- **Редактор переводов** (таблица строк, покрытие, экспорт) — не начат.
- **Настройки чтения Morihime** — шаблон настроек покрывает скорость/автопрокрутку/громкости,
  но не blip-звуки и громкость отдельных персонажей (это код, не экран).
- **Live-reload** (мост IDE↔игра, `jump/show_screen/reload`) — следующий шаг после
  одноразового предпросмотра.
