# RenPy Studio 0.2.1 — P0: надёжность и безопасность

Патч поверх 0.2.0. Новых экранов нет: это исправления того, что могло укусить в работе.

## Undo без «шума»

Инспектор сохраняет правку каждые ~450 мс. Раньше каждый такой вызов делал полный снимок
проекта в историю: печать одной реплики забивала стек отката десятками копий и гоняла память.

- `Store::checkpoint_tagged(key)` склеивает подряд идущие правки одного объекта в один шаг
  (окно 1,2 с). Ключи: `node:<id>`, `scene:<id>`, `character:<id>`, `variable:<id>`.
- Любая другая мутация (добавить блок, сменить сцену) закрывает серию — следующий шаг новый.
- `undo`/`redo`/`clear_history` сбрасывают склейку.
- Итог: текст реплики отменяется целиком, а не по символу; снимков в истории в разы меньше.

## Ключ провайдера — в DPAPI

Раньше ключ лежал в `settings.json` открытым текстом. Теперь:

- Ключ шифруется `CryptProtectData` (текущий пользователь Windows + энтропия приложения) и
  хранится как `apiKeyEnc` (hex). Без DPAPI (не-Windows) остаётся явный fallback `apiKeyPlain`.
- Плейнтекстовый ключ никогда не сериализуется: ни на диск, ни в webview. UI получает только
  флаг `hasKey` и показывает «Ключ сохранён (DPAPI)».
- Пустое поле ключа при сохранении настроек означает «оставить как есть»; для удаления есть
  отдельная команда `ai_forget_key` и кнопка «Удалить ключ».
- Старые настройки читаются как раньше: ключ подхватывается из `apiKey` и при первом сохранении
  переезжает в `apiKeyEnc`.

## CSP

`app.security.csp` больше не `null`: `default-src 'self'`, скрипты только свои, стили —
с `'unsafe-inline'` (React-инлайны), картинки/медиа — `'self'`, `data:`, `blob:` и протокол
`studio-asset`. В dev-режиме CSP отключён (`devCsp: null`), чтобы не ломать HMR.

## Надёжность экспорта

- Файл, который сцена больше не генерирует, но который правили снаружи, остаётся в манифесте.
  Раньше запись терялась, и файл «осиротел» навсегда — последующий `force`-экспорт его уже не удалял.
- `lookup_node` больше не удваивает префикс: `./game/x.rpy` и абсолютный путь
  `C:/…/game/x.rpy` корректно мапятся на `game/x.rpy`.

## Плагины

- `clean_target` работает по компонентам пути, а не по байтовым индексам: lower-case путь
  больше не может сдвинуть срез (потенциальная паника на не-ASCII именах).
- Демо-хвосты (`tl/…`, `script.rpy`, `screens.rpy`, …) отбрасываются и вне `game/` — раньше
  они проезжали как «свободные» скрипты в `plugins/<id>/`.
- Траверсал `../evil.rpy` теперь отклоняется целиком (раньше «сплющивался» в безопасное имя).
- Ветка установки одиночного файла (`kind="file"`) больше не перезаписывает существующий файл.
- **Авто-lint после включения/отключения плагина**: студия сразу прогоняет экспорт + `renpy lint`
  и говорит в тосте, чистый ли проект. Так «включил и сломалось» видно сразу, а не при запуске.

## Кодировка каталога плагинов

`plugins.rs` хранил русские названия и описания плагинов в дважды перекодированном виде
(UTF-8 → cp1251 → UTF-8): в интерфейсе вместо «Tasks — список задач» было «Tasks вЂ” СЃРїРёСЃРѕРє…».
Текст восстановлен, каталог снова читается по-русски.
